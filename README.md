# 🎮 Game Hub Website

A fun, interactive game website with horror games, AI chatbots, and free movie platforms!

## ✨ Features

- **🎮 Games**: Play the scary Granny horror game
- **🤖 AI Chatbots**: Free Fliped.ai and Deep.ai chatbots
- **🎬 Movies**: Access 6 free movie platforms (no sign-up needed)
- **🔒 Tab Cloaker**: Hide the tab to look like Google
- **🌙 Themes**: Dark, Light, and Neon modes
- **⌨️ Keyboard Shortcuts**: Quick navigation with keyboard

## 🚀 Quick Start - Deploy for FREE

### Option 1: GitHub Pages (EASIEST - Recommended)

1. Go to your repository settings: https://github.com/max122283893/game-website/settings
2. Scroll down to **"Pages"** section
3. Under "Source", select **"Deploy from a branch"**
4. Select **"main"** branch and **"/ (root)"** folder
5. Click **"Save"**
6. Wait 1-2 minutes for deployment
7. Your site will be live at: **https://max122283893.github.io/game-website/**

### Option 2: Netlify (Also FREE)

1. Go to https://netlify.com
2. Sign up with GitHub
3. Click "New site from Git"
4. Select your game-website repository
5. Click "Deploy site"
6. Your site will be live in minutes!

### Option 3: Vercel (Also FREE)

1. Go to https://vercel.com
2. Sign up with GitHub
3. Click "New Project"
4. Import your game-website repository
5. Click "Deploy"
6. Your site will be live instantly!

## 🎮 How to Use

1. **Navigate**: Click the menu button (☰) or use keyboard shortcuts
2. **Play Games**: Click "Play Game" to launch Granny
3. **Chat with AI**: Switch between Fliped.ai and Deep.ai
4. **Watch Movies**: Click any movie platform to watch free content
5. **Change Settings**: Customize theme, sound, and tab cloaking
6. **Cloak Tab**: Hide the website to look like Google (perfect for school!)

## 🐛 Troubleshooting

**Games not loading?**
- Check your internet connection
- Disable ad blockers
- Clear browser cache

**Chatbots not showing?**
- Reload the page
- Check if Fliped.ai or Deep.ai are online
- Try a different browser

**Tab cloaker not working?**
- Refresh and try again
- Clear browser cookies
- Use in a new tab
